# Image Restoration Comparison / 画像復元の比較

[English comparison](https://mxd2024.github.io/image-restoration-comparison/en/) · [日本語の比較画面](https://mxd2024.github.io/image-restoration-comparison/)

An interactive gallery comparing **CODiff**, **SwinIR**, and an **experimental WaveMamba port** on photographs and paintings with added JPEG compression or tonal quantization.

Move the divider to compare the original, degraded input, and restoration output at the same coordinates and scale. The viewer supports full-width display, fit-to-screen, native 100% and 200% views, and draggable comparison boundaries. Japanese and English pages share the same images and metric values.

This repository contains static pages, saved comparison images, and supplementary metric records. Inference code, model weights, runtime environments, and internal logs are not included.

See [Sources, credits and test scope](https://mxd2024.github.io/image-restoration-comparison/en/credits.html) for image attribution, processing conditions, and limitations. No blanket license is granted for all images or pretrained models.

## 日本語

JPEG圧縮や階調の変化を加えた写真・絵画について、CODiff・SwinIR・WaveMamba移植版による細部・色・質感の変化を比較できるギャラリーです。

境界を動かし、原画・劣化画像・復元結果を同じ位置・倍率で見比べられます。横幅いっぱいの表示、画面内への全体表示、原寸100%・200%表示に対応しています。

掲載内容は静的ページ・比較画像・補助指標の記録です。推論コード・モデル重み・実行環境・内部ログは含めていません。
